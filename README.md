# ポートフォリオサイト - 山木一平

## 概要

ゲーム開発とグラフィックスプログラミングの作品を紹介するポートフォリオサイトです。

https://ippeiyamaki.github.io/

## 主な機能

- **プロフィール**: 写真・所属・連絡先・好きなゲーム
- **作品カード**: グリッド表示での作品一覧
- **作品ページ**: 動画・概要・実装した機能・スクリーンショットをまとめた作品ごとのページ
- **レスポンシブデザイン**: スマホ・タブレット・PC に対応
- **ダークモード**: OS の設定に合わせて配色を切り替え

## 作品一覧

### 1. 作品名（仮）
- **技術**: C++, DirectX12
- **特徴**: 作品説明（仮）

### 2. DirectX11 フレームワーク
- **技術**: C++, DirectX11, HLSL
- **特徴**: C++20 と DirectX11 で作った自作のゲームフレームワーク。MMD のキャラクター（PMX・VMD、IK、モーフ、揺れもの）、カスケードシャドウマップ、ポストエフェクト、自作の物理、デバッグの道具など

### 3. 天気の箱庭（仮題）
- **技術**: C++, DirectX12
- **特徴**: 天気で自然を育てる箱庭のシミュレーションゲーム（制作中）。谷のシミュレーション、ブラウザー版の試作と同じ結果を出す C++ への移植、木の手続き生成（試作）

### 4. こたつでみかん
- **技術**: Unity, C#
- **特徴**: ゲームジャムでチームで作った 2D のゲーム。ゲーム画面のプログラムを担当し、アイテムのルールを ScriptableObject のデータで決める作りにした
